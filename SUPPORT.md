# Support

Start with the [Getting Started guide](docs/GETTING_STARTED.md) and
[Troubleshooting guide](docs/TROUBLESHOOTING.md). For reproducible bugs, open a
GitHub issue using the bug template and include the firmware version, build
environment, panel markings, serial output with secrets removed, and exact
steps. Use Discussions for setup questions and feature ideas when enabled.

Never post `include/secrets.h`, Tailscale keys, Wi-Fi or MQTT passwords, public
IP addresses, or unredacted Home Assistant exports.
